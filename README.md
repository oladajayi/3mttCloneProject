# 3MTT Website Clone (React)

A practice project where I cloned the **3 Million Technical Talent (3MTT) website** using React.  
The goal of this project was to improve my **web development skills** by building a responsive, multi-section site with smooth scrolling navigation.

---

## 🎯 Project Purpose
- Practice React concepts (components, props, hooks)
- Work with `useRef` and `forwardRef` for smooth scrolling to sections
- Build reusable and modular UI components
- Improve layout structuring and responsive design skills
- Gain hands-on experience by cloning a real-world website (3MTT)

---

## 🚀 Features
- **Hero Section** with introduction
- **About Section**
- **Phases Section**
- **Skills Component**
- **Building Workforce Section**
- **Swiper/Carousel** for showcasing
- **Partners Section**
- **FAQ Section**
- Smooth scroll navigation between sections

## 🛠️ Installation & Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/oladajayi/3mttCloneProject.git

    Navigate into the project folder:

cd 3mtt-clone

Install dependencies:

npm install

Run the development server:

npm run dev

Open in browser:

    http://localhost:5173

🎯 Usage

    Visit /home → loads the homepage (Hero section first).

    Visit /about → loads the same homepage but smoothly scrolls to the About Section.

    Scroll naturally to explore Phases, Skills, Partners, FAQs, etc.

🧩 Tech Stack

    React (with hooks)

    Vite (development build tool)

    CSS / Tailwind / Bootstrap (depending on what you used for styling)
